# 予算・収支管理スプレッドシート用スクリプト (2025.08.16)

Googleスプレッドシートで動作する、個人の家計管理および物販（EC・メルカリ等）の収支・予算を一本化して管理するためのGoogle Apps Script (GAS) です。

---

## 概要

本スクリプトは、日々の個人支出・収入に加えて、物販事業（仕入れ・売上）の収支状況を効率的に集計・管理することを目的としています。
固定費・変動費を明確に分離し、月ごとの予算進捗や手元に残る利益（キャッシュフロー）を可視化します。

---

## 主な管理項目

### 1. 収入管理（Income）
* **固定収入**: 毎月の定額収入（給与、小遣いなど）
* **変動収入**: 物販の売上金、フリマアプリ利益、臨時収入など

### 2. 支出管理（Expenses）
* **固定支出**: 毎月発生する固定費（スマホ通信費、各種サブスクリプションなど）
* **変動支出**: 
  * **物販関連**: 商品の仕入れ費用、梱包資材・送料など
  * **個人関連**: 日常の買い物、娯楽費、雑費など

---

## 機能・特徴

* **収支の自動集計・分類**: 入力データに基づき、固定/変動・個人/物販のカテゴリ別に自動集計
* **予算・進捗管理**: 設定した月間予算に対する消化率・残額の自動計算
* **物販収支の可視化**: 個人家計と物販の資金フローを明確に分離して把握可能

---

## スプレッドシートの推奨構成

本スクリプトを使用するスプレッドシートは、以下のシート構成を想定しています。

| シート名 | 役割・内容 |
| :--- | :--- |
| **ダッシュボード / 概要** | 今月の収支合計、予算進捗、手元残高のグラフ・サマリー表示 |
| **収入・支出入力** | 日々の取引（日付、分類、項目名、金額、区分）の明細ログ |
| **マスタ設定** | 支出カテゴリ（固定/変動）、サブスク一覧、月間予算の設定 |

---

## 導入・設定手順

1. 対象のGoogleスプレッドシートを開きます。
2. 上部メニューの **[拡張機能]** ＞ **[Apps Script]** を選択します。
3. 本リポジトリの `.gs` ファイル（スクリプトコード）の内容をエディタに貼り付けます。
4. ファイルを保存（`Ctrl + S` または `Cmd + S`）し、必要に応じてトリガー設定（自動実行設定）を行います。
